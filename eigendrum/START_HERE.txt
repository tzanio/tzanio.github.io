EIGENDRUM — MFEM EDITION v3.2
NO NPM REQUIRED

1. Open a terminal in this directory.
2. Run:

       python3 -m http.server 8000

3. Open this address in a browser:

       http://localhost:8000/

Do not double-click index.html or use a file:// URL. The finite-element solver
runs in a JavaScript module worker and requires an HTTP origin.

TIME-DEPENDENT GLVIS EXPORT

1. Strike the membrane in the browser.
2. Click "Export last vibration".
3. Extract the downloaded ZIP.
4. In that extracted directory, run either:

       python3 play_glvis.py --launch

   or start GLVis separately and run:

       glvis
       python3 play_glvis.py

Manual frame stepping is also available:

       glvis -run eigendrum.glvs

Press Space to advance the braced frames.
