# MFEM logo artwork

`assets/mfem-logo.png` is the unmodified, transparent MFEM logo from the
official MFEM repository, `doc/logo-small.png` in MFEM v4.10 at commit
`d964264cdb9a13e94a201b6c236c7721e0c8765f`:

https://github.com/mfem/mfem/blob/d964264cdb9a13e94a201b6c236c7721e0c8765f/doc/logo-small.png

The same finite element sphere artwork appears on the official project site:
https://mfem.org/

The original 90 × 90 PNG is used for the header and favicon without recoloring,
redrawing, cropping, or changing the original image. MFEM's BSD-3-Clause license
is included in `MFEM-LICENSE`.
